# AI Client Report Generator

Автоматическая генерация PDF-отчётов по диалогам с клиентами с использованием ИИ (через ProxyAPI.ru) и HTML-шаблонов.

## Архитектура

```
├── main.py               # Точка входа: CLI + интерактивное меню
├── ai_processor.py       # Анализ диалога через LLM (ProxyAPI)
├── pdf_generator.py      # Рендеринг HTML-шаблона → PDF
├── templates/            # HTML-шаблоны отчётов
│   ├── default.html      # Синяя гамма, выравнивание слева
│   └── green_right.html  # Зелёная гамма, выравнивание справа
├── examples/             # Примеры транскрибаций для тестирования
│   └── transcription.txt
├── fonts/                # Шрифты для кириллицы в PDF (Arial)
├── reports/              # Сгенерированные PDF-отчёты
├── .env.example          # Шаблон конфигурации
├── requirements.txt      # Зависимости
└── README.md
```

## Установка

### 1. Клонируйте проект и создайте виртуальное окружение

```bash
python -m venv .venv
```

### 2. Активируйте окружение

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
.venv\Scripts\activate.bat
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Системные зависимости не требуются — PDF генерируется через fpdf2 (чистый Python).

### 4. Настройте конфигурацию

```bash
copy .env.example .env
```

Откройте `.env` и вставьте ваш API-ключ ProxyAPI:

```env
PROXYAPI_KEY=sk-ваш_ключ
PROXYAPI_MODEL=openai/gpt-5-mini
TEMPLATE_PATH=templates/default.html
```

> Ключ можно получить в [личном кабинете ProxyAPI](https://console.proxyapi.ru/keys).

## Использование

### Интерактивное меню

```bash
python main.py
```

Программа покажет список `.txt`-файлов из папки `examples/` с нумерацией:

```
=======================================================
   AI CLIENT REPORT GENERATOR
=======================================================

Доступные транскрибации (папка examples/):
  1. transcription.txt

Дополнительные действия:
  0. Ввести текст диалога вручную
  9. Указать путь к произвольному файлу
  q. Выход
-------------------------------------------------------

Выберите пункт меню: _
```

- **Введите номер** (1, 2, ...) — выберите файл из `examples/`
- **0** — введите текст диалога вручную (пустая строка завершает ввод)
- **9** — укажите путь к любому `.txt`-файлу
- **q** — выход

После выбора транскрибации программа предложит **выбрать HTML-шаблон** отчёта:

```
Доступные шаблоны отчёта (папка templates/):
  1. default.html
  2. green_right.html
  0. Автоматический выбор (последний изменённый шаблон)

Выберите шаблон: _
```

- **Введите номер** — используйте соответствующий шаблон для этого отчёта
- **0** — автоматический выбор: берётся последний изменённый `.html` в `templates/`

### CLI-режим (для скриптов и автоматизации)

```bash
python main.py --file examples/transcription.txt
python main.py --file dialog.txt --template templates/green_right.html
```

### Результат

```
⏳ Анализ диалога с помощью ИИ...
✅ Диалог проанализирован успешно!
   Клиент: Дмитрий
   Тема: Инвестиции для начинающих
   Настроение: Позитивное

⏳ Генерация PDF-отчёта...

=======================================================
📄 Отчёт успешно создан: reports/report_2025-11-13_15-30.pdf
=======================================================
```

## Смена шаблона

`pdf_generator.py` универсален: для смены макета достаточно изменить/добавить HTML-файл в `templates/` — сам код менять не нужно.

**Способ 1** — Выберите шаблон в интерактивном меню (появляется после выбора транскрибации).

**Способ 2** — Положите новый `.html`-файл в папку `templates/` и укажите его через `--template`:
```bash
python main.py --file dialog.txt --template templates/my_style.html
```

**Способ 3** — Автоматический выбор: используется последний изменённый `.html` в `templates/` (пункт `0` в меню или поведение по умолчанию).

**Способ 4** — Задайте шаблон по умолчанию в `.env`:
```env
TEMPLATE_PATH=templates/my_custom_template.html
```

> **Важно:** fpdf2 поддерживает ограниченный набор HTML-тегов (`h1`–`h6`, `p`, `div` c `bgcolor`, `font` c `color`/`size`, `b/i/u`, `ul/ol/li`, `hr`, `br`, `table`). Используйте inline-атрибуты (`align`, `bgcolor`) вместо CSS-классов.

Шаблон — стандартный HTML с Jinja2-переменными:

| Переменная | Описание |
|---|---|
| `{{ client_name }}` | Имя клиента |
| `{{ topic }}` | Тема обращения |
| `{{ main_request }}` | Основной запрос |
| `{{ mood }}` | Настроение |
| `{{ next_steps }}` | Следующие шаги (HTML) |
| `{{ transcript }}` | Транскрибация диалога (HTML) |
| `{{ generated_at }}` | Дата и время генерации |

## Примеры

### Пример транскрибации

Файл `examples/transcription.txt` содержит реалистичный диалог оператора с клиентом. Для тестирования выберите его через меню (пункт 1).

### Формат транскрибации

Свободный текст, где реплики могут помечаться:
```
[14:02:15] Оператор: Добрый день! ...
[14:02:20] Клиент: Здравствуйте...
```

Или просто текст диалога без таймкодов.

## Логирование

Все этапы логируются в консоль:
- Отправка запроса в LLM
- Получение и парсинг ответа
- Рендеринг шаблона
- Конвертация PDF
- Ошибки с полным стектрейсом

## Технологии

- **Python 3.10+**
- **[ProxyAPI.ru](https://proxyapi.ru)** — прокси для LLM (OpenAI SDK совместим)
- **openai** — официальный SDK, направлен на `https://api.proxyapi.ru/v1`
- **fpdf2** — генерация PDF (чистый Python, без системных зависимостей)
- **Jinja2** — HTML-шаблонизатор
- **python-dotenv** — конфигурация через `.env`

## Шрифты для кириллицы

fpdf2 не встраивает системные шрифты автоматически, поэтому в папке `fonts/` лежат файлы Arial (обычный, жирный, курсив, жирный курсив). Генератор регистрирует их как семейство `Custom` — кириллица отображается корректно.

Если папка `fonts/` пуста (например, после клонирования на новую машину), скопируйте шрифты вручную:

```powershell
Copy-Item "C:\Windows\Fonts\arial.ttf" fonts\
Copy-Item "C:\Windows\Fonts\arialbd.ttf" fonts\
Copy-Item "C:\Windows\Fonts\ariali.ttf" fonts\
Copy-Item "C:\Windows\Fonts\arialbi.ttf" fonts\
```

На Linux/macOS подойдут любые TTF-шрифты с кириллицей (DejaVu Sans, Liberation Sans) — положите их в `fonts/` с теми же именами или измените пути в `pdf_generator.py`.
